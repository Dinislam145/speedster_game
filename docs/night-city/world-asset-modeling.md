# ТЗ на моделирование окружения ночного города в Blender

Набор охватывает 18 объектов для торговых фасадов и тротуаров Speedster. Для каждого объекта при подготовке отдельного ТЗ использовать одноимённый PNG как основной референс. Раменная, бар и мини-маркет — цельные модули для первых этажей существующих зданий.

## Свет и прозрачное стекло

- Для каждого светящегося ассета указать поверхность, имя материала для поиска после экспорта и положение будущего источника Phaser в локальных координатах модели. Координаты указывать в метрах с обозначением системы осей. Эмиссия материала отвечает за яркость самой детали. Источник в Phaser освещает соседние поверхности. Ореол и световое пятно создаются в движке.
- Столбик и бордюр используют общую неоновую пару. Рабочие значения — бирюзовый `#36E6EE` и розовый `#FF48AF`. Для каждого из двух объектов подготовить один GLB с отдельным нейтральным рассеивателем. В Phaser выставлять цвет и состояние по экземплярам. При приёмке проверить два соседних экземпляра разных цветов и третий с погашенной подсветкой.
- Стекло витрины, двери и автомата сделать отдельной именованной поверхностью с простым нейтральным прозрачным материалом. За стеклом должно быть видно содержимое. Предусмотреть место для источника. Загрузчик Phaser передаёт альфу базового цвета, а режим glTF `alphaMode` игнорирует. Прозрачность экспортированного GLB проверять в Phaser с позиции игрока при включённом и выключенном внутреннем освещении.

## Формат отдельных ТЗ и приёмка моделей

- Один ассет на один Markdown-файл. Для комплекта отдельных ТЗ использовать каталог `design/world-specs/`. Имя файла совпадает с именем PNG. В начале каждого документа разместить соответствующую изометрию.
- Задать проектные габариты Ш × Г × В в метрах, лицевую сторону, точку крепления или опоры, состав геометрии, лимит треугольников и детали атласа. Для фасадов использовать общий масштаб двери, стойки и сиденья. Для мощения, решётки и бордюрного светильника применять совместимый профиль тротуара.
- Сдавать исходник `.blend` и один самодостаточный `.glb` на ассет. Использовать 1–3 материала и встроенный PNG-атлас 256–512 px, где нужна текстура. Проверить силуэт с игрового расстояния, масштаб, материалы и работу светящихся частей по правилам проекта. [Пайплайн моделирования](../rules/pipelines/asset_modeling.md)
