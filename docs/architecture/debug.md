# `debug.ts` — читы и инспекция состояния

**Роль:** регистрирует инструменты разработчика, которые работают с любого экрана:
переключение карты, телепорт по трассе, «две минуты заезда», плюс отдаёт `inspect`
состояние заезда. Вызывается один раз из `main.ts` до `game.start()`.
**Строк:** 37. **Экспортирует:** `addDebugControls()`.
**Используется:** `main.ts`; в игре — через `play -- "cheat ..."`.

## `CHECKPOINTS`

| Ключ | Значение | Откуда |
|---|---|---|
| `right` | `RIGHT_ENTRY = 96` | начало правого поворота |
| `left` | `LEFT_MIDDLE = 280` | середина левой дуги |
| `wrap` | `311.3` | стык периода декораций (312 м) |
| `shop` | `34` | первая секция с витринами |
| `longrun` | `119 · CRUISE = 4760` | две минуты езды |

## `jump(distance)`

```ts
if (game.scenes.current !== 'play') return 'Start a drive first';
seekDrive(distance);
return 'Distance ' + distance + ' m';
```

Прыжок **не** пересоздаёт сцену: он меняет `run.distance`, а следующий шаг `draw()`
сам переставит секции/переоденет слоты и вызовет `snap()`. Поэтому переход не
«пролетает» сквозь город, а сразу оказывается в нужной точке.

## Зарегистрированные читы

Все — через `game.cheats.add({ name, args?, does, run })`:

| Имя | Аргументы | Что делает |
|---|---|---|
| `map` | `night` / `day` | `selectMap(map)` и `scenes.go('title')` — карта перестраивается при следующем входе в заезд |
| `checkpoint` | `right`/`left`/`wrap`/`shop` | `jump(CHECKPOINTS[key])` |
| `longrun` | — | `jump(4760)` — состояние, как после двух минут |

Возвращаемая строка печатается инструментом `play` (`cheat longrun` → `Distance 4760 m`).

## `game.inspect.state(() => ({ ...run }))`

Отдаёт копию `run` — время, дистанцию, скорость, `x`, `hint`, `cycles`, `map`,
`sections`. По `inspect` в `play` видно состояние заезда, не открывая код.

## Почему `map` идёт через титул

`selectMap` только меняет переменную; дорога строится в `openRoad()`. Если бы чит
менял карту на ходу, старый город остался бы на экране до рестарта. Переход на
`title` гарантирует, что следующий `play` начнётся с чистого листа — и это тот же
путь, которым идёт игрок.

## Как добавить чит

```ts
game.cheats.add({
    name: 'laps',
    args: 'n',
    does: 'Jump n circuits ahead',
    run: (n) => jump(Number(n) * CIRCUIT_LENGTH),
});
```

Требования Phaser AE: читы регистрируются в `debug.ts` при загрузке; прыжок должен
проходить через штатный путь игры (`seekDrive` + шаг), а не телепортировать объекты
руками; каждый чит стоит один раз проверить через `play -- "cheat ..."`.
