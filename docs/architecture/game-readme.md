# `game/README.md` — краткая справка проекта

**Роль:** «за что взяться первым делом». Документ для человека, не для кода.

## Что в нём есть

- Название и описание: вертикальный прототип гонки на Phaser AE, ядро `core-3d`.
- Команда запуска: `node phaser/cli/bin/phaser-ae.mjs serve` (порт задаётся
  `--port 4184`).
- Ссылки: ТЗ (`../docs/prototype-spec.md`), контрольный список (`NOTES.md`),
  руководство по 3D (`docs/make-a-3d-game.md`).
- Команды сборки и smoke-теста:
  ```sh
  node phaser/bin/bake.mjs build game dist
  node phaser/bin/bake.mjs smoke game --seconds 125
  ```

## Чем отличается от `NOTES.md`

| `README.md` | `NOTES.md` |
|---|---|
| что это и как запустить | как проверять и где что лежит |
| стабильный, редко меняется | дописывается после каждой проверки |

## Что стоит поправить при следующем обновлении

`NOTES.md` и `README.md` описывают только дневной прототип; ночной город, читы
`map`, `checkpoint`, `longrun` и папка `shots/` там не упомянуты. Актуальная карта
кода — в этом каталоге (`docs/architecture/`).
