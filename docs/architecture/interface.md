# `interface.ts` — картинки HUD и зоны нажатия

**Роль:** рисует все элементы интерфейса процедурно и разделяет «вид» (картинка) и
«ввод» (прозрачная кнопка движка). Никакой логики заезда здесь нет.
**Строк:** 127. **Экспортирует:** `prepareInterface()`, `showGraphic(key, x, y)`,
`control(key, x, y, click)`.
**Используется:** `main.ts` (подготовка), все три сцены.

## Палитра и хранилище

```ts
const INK = '#142d3a', PAPER = '#fff4da', ORANGE = '#ff692e';
const frames = new Map<string, { frame: number; width: number; height: number }>();
```

`frames` — «каталог» нарисованных картинок: ключ → глобальный индекс кадра и размер.
Нужен, потому что `game.paint` возвращает только индекс, а размеры спрайта и кнопки
надо знать в пикселях.

## Вспомогательные функции

| Функция | Что делает |
|---|---|
| `paint(key, w, h, draw)` | рисует картинку и регистрирует её размер в `frames` |
| `lettering(ctx, text, x, y, size, color, weight=700)` | текст шрифтом `Arial, sans-serif` |
| `cutPanel(ctx, w, h, color)` | панель со срезанным правым нижним углом (15 px) — «техно»-вид |
| `showGraphic(key, x, y)` | спавнит спрайт слоя `hud` с нужным кадром и размером |
| `control(key, x, y, click)` | `showGraphic` + прозрачная `game.ui.button` для ввода |

## Почему картинка и кнопка раздельно

`game.ui.button` умеет: захват пальца, попадание, фокус с клавиатуры и геймпада,
нажатие/отпускание, доступность. Но её вид — это стиль скина (`fill`, `border`,
`shadow`…). В проекте вид нарисован вручную (кириллица на всех платформах, свой
скошенный край), поэтому кнопка делается **полностью прозрачной**:

```ts
style: { fill: '#00000000', border: 0, shadow: 0, gloss: 0, bevel: 0, radius: 0 }
```

и кладётся ровно на картинку. Координаты кнопки задаются от центра экрана
(`x - width/2`, `y - height/2`), потому что у виджета `anchor: 'center'`.

## Что рисуется в `prepareInterface()`

| Ключ | Размер | Содержимое |
|---|---|---|
| `masthead` | 628×154 | панель, оранжевая полоса слева, «SPEEDSTER» с наклоном (transform `-0.16`), три шеврона, подпись «СВОБОДНЫЙ ЗАЕЗД» |
| `start` | 428×78 | оранжевая кнопка «СТАРТ» + стрелка |
| `resume` | 428×78 | оранжевая кнопка «ПРОДОЛЖИТЬ» |
| `restart` | 428×78 | тёмная кнопка «НАЧАТЬ СНАЧАЛА» |
| `hint` | 486×60 | «Веди пальцем влево и вправо» |
| `telemetry` | 218×92 | панель с подписью «ДИСТАНЦИЯ / М» |
| `pause-key` | 74×74 | две вертикальные полоски паузы |
| `pause-title` | 428×80 | «ПАУЗА» |

`key === 'restart'` — единственное отличие в цикле кнопок: тёмная панель и светлый
текст.

## Как это используется

```ts
// Title.ts
showGraphic('masthead', 360, 133);
control('start', 360, 1174, () => game.scenes.go('play'));

// Play.ts
showGraphic('telemetry', 139, 79);
const hint = showGraphic('hint', 360, 1174);
control('pause-key', 653, 70, () => game.scenes.push('pause'));
hint.visible = run.hint;

// Pause.ts
showGraphic('pause-title', 360, 508);
control('resume', 360, 639, () => game.scenes.pop());
control('restart', 360, 740, () => game.scenes.go('play'));
```

`showGraphic` возвращает объект, поэтому у подсказки можно менять `visible`.

## Слои и координаты

- Всё на слое `hud` — рисуется поверх 3D, в пикселях 720×1280.
- `x, y` — **центр** спрайта.
- Внутри слоя порядок: сначала `z`, при равном `z` — порядок спавна. Поэтому число
  дистанции в `Play` создаётся с `z: 8` и попадает поверх панели телеметрии.
- Из-за `letterbox` полосы по краям не мешают: HUD живёт в логическом кадре.

## Где править

| Хочу | Правка |
|---|---|
| другой текст | строки в `lettering` / массиве кнопок |
| другой цвет | `INK`, `PAPER`, `ORANGE` |
| другую форму панели | `cutPanel` |
| новую кнопку | `paint(key, ...)` в `prepareInterface` + `control(key, ...)` в сцене |
| шрифт | `ctx.font` в `lettering` (для кириллицы лучше Arial/sans; `mono-bold` в `game.text` — шрифт движка) |
