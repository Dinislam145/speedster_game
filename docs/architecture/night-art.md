# `night-art.ts` — процедурные текстуры ночного города

**Роль:** рисует **все** картинки ночной карты в атлас: небо, вывески, окна, витрины,
мокрое полотно, тротуар, переход. Ни одной геометрии — только `game.paint`.
**Строк:** 273. **Экспортирует:** `prepareNightArt()`, `NEON`, `NAMES`, `NIGHT_HAZE`.
**Используется:** `main.ts` (вызов), `night-city.ts` (цвета/имена/туман).

## Экспорты и константы

| Имя | Значение | Смысл |
|---|---|---|
| `NEON` | `['#57d6e3','#ee60a8','#ffb566','#aeff00','#00ac4a','#ff0000']` | 6 неоновых цветов |
| `NAMES` | `['SORA','LOOP','KILO','VELA','AXON','NOVA']` | 6 «брендов» на вывесках |
| `NIGHT_HAZE` | `#0b081a` | цвет дымки/низа неба (он же `fogColor`) |
| `W`, `H` | 384, 768 | размер текстуры дороги |

Все картинки рисуются с `{ res: 1 }` — в натуральную величину (по умолчанию `paint`
рисует в 2× для плотных экранов; здесь текстуры и так большие и их много).

## Вспомогательные функции

### `noise(seed)`

Простой LCG: `seed = (seed·1664525 + 1013904223) >>> 0`, возвращает `0…1`.
Детерминированный «случайный» поток — одинаковые текстуры при каждой загрузке.

### `sign(c, k)` — вывеска 128×384

Тёмная панель `#111425`, неоновая рамка, белая плашка `01…06`, четыре буквы имени
каждой по 58 px, тип заведения (`OPTICS`, `TRANSIT`, `WORKS`, `RADIO`, `SYSTEMS`,
`HOTEL`) и восемь точек внизу. Вертикальная вывеска — потому что в кадре она видна
сбоку и должна читаться с большого расстояния.

### `windows(c, k)` — фасад 256×512

- 6 вариантов: свои цвета основы, число колонок `[7,4,6,5,4,8]` и этажей
  `[12,10,15,14,11,13]`.
- В каждом этаже случайный «зажжённый» участок из 1–3 окон; свет — из палитры
  `['#83abb9','#d2ad90','#467a90','#a77a8e']`.
- Три варианта «инфраструктуры»: горизонтальные пояса, вентиляционная шахта с
  жалюзи, вертикальные трубы.
- Тёмные края по 3 px — чтобы на стыке двух стен не было светлой полосы.

### `shop(c, k)` — витрина 512×192

Три типа (`k % 3`):

| тип | Что рисуется |
|---|---|
| 0 | 5 светящихся витрин с отражением-градиентом |
| 1 | витрины с горизонтальными жалюзи-рольставнями |
| 2 | витрина + прилавок/интерьер (тёплый свет `#ffbb80`) |

Всегда сверху — название бренда и тип заведения неоновым цветом.

### `pavement(c)` — тротуар 96×384

Тёмные плиты 96×32 со смещённым швом (кладка «в разбежку»), один люк с решёткой.

### `road(c, left, right)` — полотно 384×768

Самая важная текстура: она задаёт «мокрый неон» и разметку.

| Элемент | Как сделано |
|---|---|
| основа | `#18202d` |
| пятна света у бортов | радиальный градиент, растянутый по Y в 2.5 раза, цвет левого/правого бренда |
| отражения | 480 тонких вертикальных штрихов на сторону, alpha 0.012…0.087 |
| зерно | 2200 точек `#d2e6ff09` / `#02071925` |
| пунктир ×3 | x = `W/2 ± W/6` (то есть на 1/3 и 2/3 ширины), яркость `#ddf5ff` с `shadowBlur` |
| кромка | `#47aab4`, 2.6 px, плюс слабое свечение |
| заливка от вывески | вертикальный градиент цвета бренда у самой кромки |

`left`/`right` — индексы брендов слева и справа. Комбинаций 3×3 = 9, поэтому в
`prepareNightArt` рисуется `wet-0-0 … wet-2-2`. **Почему 3, а не 6:** дорога должна
перекликаться с ближайшими вывесками, но 36 текстур — слишком много; индексы берутся
`style % 3`.

## `prepareNightArt()` — что регистрируется

| Картинка | Размер | Назначение |
|---|---|---|
| `night-sky` | 32×256 | вертикальный градиент `#17132c → #2b203a → NIGHT_HAZE` (растягивается на экран) |
| `night-crossing` | 512×64 | мост через дорогу: окна, диагональные связи, тёмный низ |
| `night-entry-lamp` | 8×32 | узкая тёплая полоска света у входа |
| `night-sign-0…5` | 128×384 | шесть вывесок |
| `night-windows-0…5` | 256×512 | шесть фасадов |
| `night-shop-0…5` | 512×192 | шесть витрин |
| `wet-0-0 … wet-2-2` | 384×768 | девять вариантов полотна |
| `night-paving` | 96×384 | тротуар |

Итого **25 картинок**. Все они лежат в одном атласе; `night-city.ts` берёт их через
`game.assets.frame(key).index`.

## Как это связано с геометрией

UV дороги (`ribbon()` в `night-city.ts`) — `u` поперёк, `v` вдоль 0…1 на 24 м.
Поэтому:

- 3 пунктира на текстуре = 3 пунктира на 24 м = шаг 8 м (совпадает с дневной картой);
- 12 плит тротуара на текстуре = 12 плит на 24 м;
- вывеска/окна/витрина натянуты на грань коробки один раз.

## Что менять

| Хочу | Правка |
|---|---|
| другие цвета неона | `NEON` |
| другие названия | `NAMES` (ровно 6, по 4 буквы — код рисует `NAMES[k][0..3]`) |
| светлее/темнее ночь | `NIGHT_HAZE` и градиент `night-sky` |
| другая частота пунктира | число и позиции в цикле `for (let i = 0; i < 3; i++)` в `road()` |
| больше вариантов дороги | циклы `l < 3`, `r < 3` в конце `prepareNightArt` |
