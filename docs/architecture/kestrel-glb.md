# `assets/kestrel.glb` — модель болида

**Роль:** единственный бинарный ассет игры. Низкополигональный корпус с материалами
и двумя соплами. Загружается через пак `model-files-3d`.

## Как используется

```ts
// main.ts
await game.modelFiles.load('kestrel', 'assets/kestrel.glb');

// vehicle.ts
const craft = game.modelFiles.spawn('kestrel', { id: 'craft', size: 4.13, y: HOVER });
```

## Что важно знать про `modelFiles`

- Файл читается **один раз**; `spawn` создаёт инстанс из уже зарегистрированных
  мешей (несколько материалов = несколько вызовов отрисовки, копии дешёвые).
- Модель **вписывается в единичный куб вокруг своего центра**, поэтому:
  - `size` — самый большой габарит в метрах (здесь длина 4.13 м);
  - половина модели лежит ниже её начала координат;
  - `y` у `spawn` — это центр модели, не низ. `HOVER = 0.58` поднят так, чтобы низ
    корпуса висел над полотном на несколько сантиметров.
- Углы: `yaw/pitch/roll` в радианах, `roll` используется для крена в повороте.
- В файле нет анимаций — `play()` не вызывается; сопла сделаны отдельным мешем
  `jet` (см. `art.md`), а не частью модели.

## Почему модель отдельно, а не в `assets.json`

`assets.json` принадлежит Phaser AE (перезаписывается командами `upload`/`crew`/
`pull`). `.glb` лежит рядом с кодом и грузится прямым путём — так проще править
модель и не зависеть от сети при локальной сборке.

## Как заменить модель

1. Положить новый `.glb` в `game/assets/` (имя любое).
2. Поменять путь в `main.ts`: `game.modelFiles.load('kestrel', 'assets/<новый>.glb')`.
3. Подобрать `size` в `vehicle.ts`: это длина в метрах; ширина для расчёта `MAX_X`
   задаётся константой `CRAFT_WIDTH = 2`.
4. Проверить посадку: `HOVER` ≈ половина высоты модели над полотном.

Ограничения загрузчика: glTF 2.0 (`.glb`), треугольники, до 4 костей на вершину,
материалы PBR; KTX2/WebP-текстуры и квантованные атрибуты не поддерживаются.
