# `assets.json` — ключи загружаемых файлов

**Роль:** словарь «ключ → URL» для `game.assets.load(...)`. Файл принадлежит
Phaser AE: его перезаписывают `upload`, `crew` и `pull`, поэтому **руками не
редактируется**.

## Текущее содержимое

```json
{
  "baseURL": "",
  "packs": { "title": [], "game": [] }
}
```

Пусто: все картинки в игре **процедурные** (`game.paint` в `art.ts`,
`night-art.ts`, `interface.ts`), а единственный файл-ассет — модель болида —
загружается отдельно:

```ts
game.modelFiles.load('kestrel', 'assets/kestrel.glb')
```

## Как устроен

| Поле | Смысл |
|---|---|
| `baseURL` | префикс для относительных путей (CDN, если файлы залиты на phaser.io) |
| `packs` | группы ассетов; `load(assets, { pack: 'title' })` грузит одну группу, `game` — остальные |
| ключ | имя, по которому файл потом используется: `texture: '<ключ>'`, `game.backdrop.background('<ключ>')` |

`packs` позволяют разделить загрузку: титульный экран может стартовать раньше, чем
догрузятся тяжёлые ассеты игры (в этом проекте разницы нет — файлов почти нет).

## Как добавить файл правильно

```sh
npm run -s upload -- <файл> --note "<зачем он>"      # зальёт на phaser.io и впишет ключ
```

После этого файл доступен как `texture: '<key>'` (картинка) или
`game.sound.music('<key>')` / `game.modelFiles.load('<key>', ...)` в зависимости от
типа. Копировать файл в `game/assets/` и править `assets.json` вручную нельзя: при
следующем `upload`/`pull`/`crew` запись будет перезаписана.

Модель `kestrel.glb` лежит в `game/assets/` и грузится напрямую — это исключение,
сделанное до появления `upload`; при желании её можно перевести на ключ.
