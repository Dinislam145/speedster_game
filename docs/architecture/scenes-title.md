# `scenes/Title.ts` — стартовый экран

**Роль:** титул поверх **живой** дороги. Пока игрок смотрит на логотип, под ним уже
работает заезд: город/эстакада едет, болид парит, тяга дрожит.
**Строк:** 16. **Экспортирует:** `Title` (объект сцены `{ name, enter }`).
**Использует:** `openRoad`, `control`, `showGraphic`.

## Код

```ts
export const Title = {
    name: 'title',
    enter(): void {
        const draw = openRoad();
        showGraphic('masthead', 360, 133);
        const start = () => game.scenes.go('play');
        control('start', 360, 1174, start);
        game.step('grid', (dt) => {
            draw(dt, 0);
            if (game.input.keyPressed('Space') || game.input.keyPressed('Enter')) start();
        });
    },
};
```

## Что происходит

| Шаг | Деталь |
|---|---|
| `openRoad()` | собирает `run`, дорогу, болид, камеру; сразу делает `draw(0, 0)` — первый кадр правильный |
| `showGraphic('masthead', 360, 133)` | логотип по центру, ближе к верху |
| `control('start', 360, 1174, ...)` | кнопка «СТАРТ» внизу + прозрачная UI-кнопка |
| `game.step('grid', ...)` | каждый шаг двигает мир (`draw`) и слушает Enter/Space |

`draw(dt, 0)` — нулевая боковая скорость, поэтому крен на титуле всегда 0: болид
висит ровно, слегка покачиваясь на парении.

## Почему это выгодно

- Нет отдельной «картинки титула»: то, что видит игрок, — настоящий рендер игры.
  Переход в `play` не меняет картинку, поэтому старт читается как «отпустили тормоз».
- `openRoad()` — единственное место, где строится мир; титул и заезд используют один
  и тот же путь, поэтому расхождений между ними быть не может.

## Цена

При `go('play')` сцена титула выгружается (её мир уничтожается), и `Play.enter()`
вызывает `openRoad()` **заново**. Город строится второй раз: на ночной карте это
~455 объектов и 13 пересчётов дорожных мешей. Заметно только на слабых устройствах;
если понадобится — мир можно вынести в отдельный «невидимый» слой или сделать
переход `transition` с затемнением.

## Что менять

| Хочу | Правка |
|---|---|
| другой текст/логотип | `interface.ts`, ключ `masthead` / `start` |
| анимацию появления | `game.tween` для спрайта логотипа |
| музыку на титуле | `game.sound.music(...)` в `enter` |
| старт по тапу в любом месте | `game.input.pointer?.pressed` в шаге |
| кнопку «как играть» | ещё один `control(...)` и сцена-оверлей |
