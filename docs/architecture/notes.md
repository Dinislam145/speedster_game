# `NOTES.md` — контрольный список проверки

**Роль:** памятка «как проверить руками» и карта исходников. Пишется по требованию
`phaser-ae` (после каждого законченного этапа), объём — до 80 строк.

## Что содержит сейчас

| Раздел | Содержание |
|---|---|
| Как проверить | нажать «Старт» внизу (сцена `title`, кнопка `start`); Enter/Space тоже работают |
| Управление | зажать палец/ЛКМ и вести горизонтально; позиция сохраняется после отпускания; вертикаль игнорируется |
| Края | у борта весь корпус над полотном; возврат пальца сразу уводит болид |
| HUD | дистанция слева вверху, подсказка `hint-art` исчезает после первого манёвра, кнопка `pause-key` справа |
| Пауза | `resume`, `restart`, P/Escape; сворачивание вкладки останавливает симуляцию |
| `inspect` | время, дистанция, скорость, боковая позиция, число циклов; ID корпуса — `craft` |
| Читы | `longrun` — перенос на две минуты |
| Карта исходников | по строке на файл |
| Объём версии | что сделано, чего нет (трафик, столкновения) |

## Что устарело

Документ писался под дневную карту. Сейчас в проекте есть:

- ночной город (`night-city.ts`, `night-art.ts`) и чит `map night|day`;
- читы `checkpoint right|left|wrap|shop` и `longrun`;
- `drive.ts` умеет следовать за поворотом трассы (ночная карта);
- папка `game/shots/` с кадрами проверок.

Актуальная версия карты кода — `docs/architecture/README.md` (§12).

## Как дополнять

- В «Как проверить» попадает **каждый** элемент управления и каждая сцена.
- В «Карта исходников» — новый файл одной строкой.
- В «Объём версии» — честно: что упрощено и что не сделано.
