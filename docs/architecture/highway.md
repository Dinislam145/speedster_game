# `highway.ts` — дневная эстакада и её переиспользование

**Роль:** строит прямую трёхполосную эстакаду с городом в мировых координатах и
отдаёт функцию, которая каждый шаг переставляет секции по Z. Самый простой пример
«бесконечной дороги» в проекте и источник общих констант для ночного города.
**Строк:** 162. **Экспортирует:** `buildHighway()`, `ROAD_WIDTH`, `SECTION`,
`SECTION_COUNT`, `CIRCUIT_LENGTH`.
**Используется:** `drive.ts`, `night-city.ts` (берёт размеры), `debug.ts` (косвенно).

## Константы

| Имя | Значение | Смысл |
|---|---|---|
| `ROAD_WIDTH` | 12 м | полотно |
| `SECTION` | 24 м | длина одной секции |
| `SECTION_COUNT` | 13 | секций в пуле |
| `CIRCUIT_LENGTH` | 312 м | `24 × 13`, период повтора декораций |
| `TOWER_COLORS` | 5 цветов | палитра фасадов |

## Что строит `buildHighway()`

### Мир и свет

```ts
game.render3d.lighting.preset('noon');
game.render3d.lighting.set({
    sun: {x: 0.65, y: -1, z: -0.38}, sunIntensity: 1.1, ambient: 0.66,
    skyColor: '#e3f7ff', groundColor: '#a2a29e',
    fogColor: '#d5e8e4', fogStart: 54, fogEnd: 210,
    shadows: false, environment: 0.32,
});
game.background.picture('daylight', 'stretch');
```

Плюс одна огромная коробка-«земля»: `city-floor`, `390 × 2 × 420`, центр
`y = −11, z = −126`, цвет `#668889` — под городом, чтобы между зданиями не было
пустоты.

### Секции

Для каждой из 13 секций создаётся массив коробок. Локальная функция `box(...)`
спавнит `mesh: 'box'` и запоминает **локальное смещение по Z** (`offset`); X и Y
остаются мировыми, потому что секция едет только по Z.

Состав одной секции (`i` — номер 0…12):

| Деталь | Позиция | Размер | Комментарий |
|---|---|---|---|
| `deck` | y −0.5 | 12 × 1 × 24 | верх полотна на y = 0 |
| `expansion-joint` | z −11.9, y 0.003 | 12 × 0.002 × 0.055 | тонкий шов между секциями |
| `crossbeam` | y −0.87 | 16.6 × 0.63 × 1.3 | поперечная балка |
| `parapet` | x ±6.13, y 0.18 | 0.26 × 0.5 × 24 | борт; внутренняя грань ровно 6.0 |
| `rail-inset` | x ±5.984 | 0.025 × 0.105 × 17 | синяя вставка |
| `edge` | x ±5.7, y 0.013 | 0.076 × 0.014 × 24 | светлая кромка |
| `lane` ×3 | x ±2, z −8/0/+8 | 0.11 × 0.012 × 3.35 | пунктир: 3 шт. на 24 м |
| `reflector` ×3 | x ±5.982 | 0.03 × 0.14 × 1.25 | оранжевые катафоты |
| `pier` | x ±4.7, y −7.4 | 0.85 × 13.2 × 1.35 | опора |
| `tower` | x ±(22+(n·11)%18), низ −9 | w 4…11.5, h 14…47 | фасад из палитры |
| `podium` | x ±22, y −7.7 | 20 × 4.6 × 21 | стилобат |
| `terrace` | x ±22, y −5.27 | 20.4 × 0.38 × 21.4 | терраса |
| `garden` | x ±18, y −4.97 | 7 × 0.3 × 3.7 | газон |
| `trunk` + `icosahedron`-крона ×2 | x ±(17.2 / 19.1) | 1.6 × 1.85 × 1.56 | деревья (крона — отдельный спавн) |
| `annex` | рядом с башней | 4.4 × 0.4h × 0.57d | пристройка |
| `service-line` | на фасаде | 0.2 × 0.79h × 0.14 | труба |
| `crown` | верх башни | 0.78w × 1.3 × 0.85d | парапет крыши |
| `glass` | на фасаде | 0.05 × 0.78h × 0.55d | остекление |
| `ribbon` ×4 | по этажам | w+0.18 × 0.32 × d+0.16 | межэтажные пояса |
| `mast` | при `n % 3 === 0` | 0.12 × 4 × 0.12 | антенна |
| `skyline` | x ±(49…69) | 10 × (22…69) × 13 | дальний ряд |
| `gantry` (каждая 4-я секция) | y 6.68 | 14.6 × 0.48 × 0.61 | портал |
| `gantry-leg`, `orange-foot` | x ±7.45 | 0.46 × 7.3 × 0.64 | ноги портала |
| `signal`, `lamp` ×3 | y 6.36 | — | табло и три лампы |

`n = i·2 + (side === 1 ? 1 : 0)` — детерминированный «случайный» номер, поэтому
соседние секции отличаются, а весь круг повторяется ровно через 312 м.

Важно: почти все коробки имеют `rough: 1` (матовая поверхность) — дневной город не
должен блестеть.

## Возвращаемая функция

```ts
return (distance: number) => {
    const travel = distance % CIRCUIT_LENGTH;
    for (let i = 0; i < sections.length; i++) {
        const center = SECTION - ((i * SECTION - travel + CIRCUIT_LENGTH) % CIRCUIT_LENGTH);
        for (const p of sections[i]) {
            const z = center + p.offset;
            const wrap = Math.abs(p.mesh.z - z) > SECTION;
            p.mesh.z = z;
            if (wrap) p.mesh.snap();
        }
    }
    return sections.length;
};
```

- `center` — мировая Z центра секции. При `travel = 0`: `i=0 → +24`, `i=1 → 0`,
  `i=2 → −24`, … `i=12 → −264`. То есть одна секция сзади камеры и 11 впереди.
- `wrap` — секция перескочила больше чем на 24 м, значит её перенесло с конца в
  начало: `snap()` отключает интерполяцию на этот кадр.
- Возвращает число секций — попадает в `run.sections` и видно в `inspect`.

## Ограничения

- Секции **переставляются**, а не создаются: число объектов постоянно (~13 × 25).
- Декорации жёстко привязаны к сетке 24 м; «неровной» геометрии здесь нет.
- Карта не изгибается: чтобы поворот, нужна ночная система (плавающее начало
  координат).
- `fogEnd: 210` меньше 264 м видимой геометрии — дальний край всегда в тумане;
  это и скрывает «конец» дороги.

## Где править

| Хочу | Правка |
|---|---|
| шире дорогу | `ROAD_WIDTH` (помнить про `MAX_X` и борта) |
| длиннее секцию | `SECTION` (и `CIRCUIT_LENGTH` пересчитается) |
| больше/pозже секций | `SECTION_COUNT` |
| другой свет/время дня | `preset(...)` и поля `set` |
| убрать туман | `fogEnd: 0` |
| меньше объектов | убрать `ribbon`/`skyline`/деревья |
