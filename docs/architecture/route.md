# `route.ts` — форма трассы

**Роль:** отвечает на вопрос «где находится дорога через `d` метров». Не знает ни о
мешах, ни о камере, ни о сценах — чистая математика, работает для обеих карт
(ночью используется постоянно, днём только для длины круга через `CIRCUIT_LENGTH`).
**Строк:** 47. **Экспортирует:** `routeAt`, `RIGHT_ENTRY`, `LEFT_MIDDLE`.
**Используется:** `night-city.ts`, `drive.ts`, `debug.ts`.

## Константы

| Имя | Значение | Смысл |
|---|---|---|
| `PERIOD` | 408 м | длина повторяющегося отрезка трассы |
| `RIGHT_ENTRY` | 96 м | где начинается правый поворот |
| `LEFT_ENTRY` | 224 м | где начинается левый поворот |
| `BLEND` | 24 м | плавный вход/выход дуги |
| `RIGHT_LENGTH` | 96 м | длина правой дуги |
| `LEFT_LENGTH` | 112 м | длина левой дуги |
| `TURN` | `(96 − 24) / 200 = 0.36` рад ≈ 20.6° | на сколько градусов поворачивает каждая дуга |
| `LEFT_MIDDLE` | `224 + 56 = 280` м | середина левой дуги (чит-точка) |

## Как получается форма

### 1. `turnFraction(s, length)` — доля поворота

Возвращает 0…1 — насколько дуга уже «выкручена» на расстоянии `s` от её начала:

- `s ≤ 0` → 0, `s ≥ length` → 1;
- внутри `BLEND` — плавный разгон по кривой
  `ramp(v) = (v − (BLEND/π)·sin(π·v/BLEND)) / 2`;
- в середине — линейный рост `(s − BLEND/2) / area`.

Форма `ramp` выбрана так, чтобы **кривизна на входе и выходе была нулевой** — руль
не «щёлкает», камера не дёргается.

### 2. `angle(s)` — угол трассы

```ts
TURN * (turnFraction(s − RIGHT_ENTRY, RIGHT_LENGTH)
      − turnFraction(s − LEFT_ENTRY,  LEFT_LENGTH))
```

Правая дуга прибавляет 0.36 рад, левая вычитает столько же, поэтому на выходе за
период трасса снова смотрит прямо. `LEFT_LENGTH` больше правой, поэтому левый
поворот чуть положе.

### 3. Интегрирование при загрузке модуля

```ts
const samples = [{ x: 0, z: 0 }];
for (let i = 0; i < PERIOD; i++) {
    const a = angle(i + 0.5);
    samples.push({ x: samples[i].x + Math.sin(a),
                   z: samples[i].z - Math.cos(a) });
}
```

Шаг 1 м, направление берётся **в середине** шага (метод средней точки) — так ломаная
не «сносится» на поворотах. На загрузке это 408 итераций, на кадре — ноль.

### 4. `routeAt(distance)`

```ts
{
  x, z,          // мировая точка трассы
  heading,       // угол в радианах, 0 = на −Z, плюс = вправо
  sin, cos       // единичный вектор «вправо»
}
```

- `lap = floor(distance / PERIOD)`, `s` — остаток внутри периода.
- Линейная интерполяция между `samples[i]` и `samples[i+1]` с касательной в середине.
- `x/z` получают смещение `lap · samples[PERIOD]` — то есть каждый следующий круг
  начинается там, где закончился предыдущий (трасса не замкнута в кольцо, а
  «уезжает» в бесконечность).
- `sin/cos` — это направление «вправо» от дороги:
  `forward = (sin, −cos)`, `right = (cos, sin)`. На это умножаются боковые смещения
  зданий и тротуаров.

## Как это читать в коде города

```ts
const origin = routeAt(mid);        // центр секции
place(..., across, ...)             // across > 0 — правая сторона дороги
p.x + across * p.cos                // мировая X
p.z + across * p.sin                // мировая Z
```

## Что менять

| Хочу | Правка |
|---|---|
| более крутые повороты | `TURN` (0.36 → больше) |
| другие места поворотов | `RIGHT_ENTRY`, `LEFT_ENTRY` |
| длиннее/короче цикл | `PERIOD` (и помнить, что `samples` строится на 1 м) |
| мягче/резче вход | `BLEND` |
| трассу с резким поворотом | нужен второй интегратор с постоянным радиусом; текущая формула даёт S-образные дуги |

Важно: `CIRCUIT_LENGTH` в `highway.ts` (312 = 24 × 13) **не связан** с `PERIOD`
(408). Это два разных периода: один — повтор декораций, другой — форма дороги.
