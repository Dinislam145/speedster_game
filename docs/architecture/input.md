# `input.ts` — относительный жест

**Роль:** превращает указатель (палец или мышь) в приращение по X за шаг. Один
экспорт, одна функция, никакого состояния сцены.
**Строк:** 20. **Экспортирует:** `dragReader()`.
**Используется:** `scenes/Play.ts`.

## Зачем свой ридер, а не готовые паки

Пак `controls-touch` даёт виртуальный стик — он «тянет» объект к позиции стика. В
этой игре нужно **относительное** управление: касание в любом месте экрана не должно
телепортировать болид; жест продолжает движение с текущей позиции, палец можно
переставить. Так же работает управление в Subway Surfers/Temple Run, и именно это
требует ТЗ.

## Код и разбор

```ts
export function dragReader() {
    let active: number | null = null,   // id текущего указателя
        previous = 0;                   // его X на прошлом шаге
    return () => {
        const p = game.input.pointer;
        if (!p || (!p.down && !p.released) || p.button > 0) {
            active = null;
            return 0;
        }
        if (active !== p.id || p.pressed) previous = p.startX;
        const dx = p.x - previous;
        active = p.down ? p.id : null;
        previous = p.x;
        return dx;
    };
}
```

| Строка | Что решает |
|---|---|
| `!p \|\| (!p.down && !p.released)` | нет касания — вернуть 0 и сбросить указатель |
| `p.button > 0` | правая/средняя кнопка мыши не управляет |
| `active !== p.id \|\| p.pressed` | новое касание (или второй палец) — начать отсчёт от **точки нажатия**, а не от прошлого кадра |
| `dx = p.x - previous` | приращение в пикселях |
| `active = p.down ? p.id : null` | после отпускания указатель «забыт», но `released` ещё отдаёт последний dx — поэтому болид доезжает жест до конца |
| `previous = p.x` | база для следующего шага |

Ключевая идея: **потреблять движение каждый шаг, даже если болид упёрся в борт**. Так
первый пиксель обратно к дороге сразу двигает машину (в `drive.steer` кламп не даёт
уехать за край, но `steer` всё равно вызывается и возвращает фактическое смещение).

## Что отдаёт и как используется

```ts
const drag = dragReader();          // в Play.enter
const shift = steer(drag());        // в шаге
draw(dt, shift / dt);               // боковая скорость для крена
```

Вертикальная составляющая жеста игнорируется полностью — это требование ТЗ.

## Мультитач

`active` и `p.id` не дают «переключиться» на второй палец посреди жеста: пока первый
держится, второй не управляет. Если первый отпущен, а второй нажат — `p.id` сменится
и отсчёт начнётся от его `startX`.

## Что менять

| Хочу | Правка |
|---|---|
| абсолютное управление (тап-в-точку) | писать другой ридер на `game.world3d.groundAt` |
| инвертировать | вернуть `-dx` |
| управление по вертикали | добавить `dy` и передавать в `drive` |
| мёртвую зону | не отдавать `dx`, пока `|dx| < n` |
