# `manifest.json` — описание игры для пекарни

**Роль:** входные данные сборки. Из него пекарня делает `engine.ts`, список
ассетов и манифест PWA. Редактируется руками; после правки — `npm run -s bake`
(или сразу `build`).

## Текущее содержимое

| Поле | Значение | Чем управляет |
|---|---|---|
| `name` | `speedster` | имя сборки/публикации |
| `screen.width/height` | 720 × 1280 | логическое разрешение, координаты HUD |
| `screen.fit` | `letterbox` | как кадр вписывается в окно (полосы по краям) |
| `screen.background` | `#9bd6e1` | цвет вне кадра (совпадает с дневным небом) |
| `seed` | 63923 | сид `game.rng` (детерминированные случайности) |
| `backgroundPolicy` | `pause` | когда вкладка скрыта, симуляция встаёт на паузу (независимо от меню паузы) |
| `packs` | см. ниже | какие паки «вкрутить» в `game` |
| `assets` | `assets/kestrel.glb` | файлы, грузящиеся по умолчанию |

## Паки

```json
"packs": [
  { "id": "typography" },
  { "id": "backdrops" },
  { "id": "backdrop-sky" },
  { "id": "backdrop-stars" },
  { "id": "core-3d" },
  { "id": "model-files-3d" }
]
```

- `core-3d` — «всё, что нужно 3D-игре»: он сам включает 23 пака (рендер, мир, HUD,
  камеру, свет, примитивы, модели, UI, звук, твины, сохранения, частицы, коллизии,
  текст, фоны). Полный список — в `engine.md`.
- `model-files-3d` — загрузчик `.glb` для болида.
- `typography`, `backdrops`, `backdrop-sky`, `backdrop-stars` уже требуются
  `core-3d`; в манифесте они перечислены явно, чтобы было видно, что игра использует
  шрифты и фоны.
- Параметры паков передаются полем `options` (например,
  `{ "id": "rig-orbit", "options": { "drag": false } }`). Сейчас опции камеры заданы
  внутри `core-3d` (`includeOptions`).

## Как добавить возможность

1. `npm run -s packs -- search "<что нужно>"` — найти пак.
2. `npm run -s packs -- info <id>` — карточка, опции, ограничения.
3. `npm run -s packs -- add <id>` — скачает пак **и его зависимости**, вставит в
   манифест в правильном порядке и перепечёт `engine.ts`.
4. Проверить, что появилось в `game`: например, `game.lights` (пак `lighting-3d`
   уже стоит, но игрой не используется).

На аккаунте Basic доступны только бесплатные паки; Pro-паки `add` откажется
ставить.

## Чего здесь нет и почему

- Нет `audio`-настроек и звуковых файлов: игра сейчас беззвучна.
- Нет `particles-3d`-эмиттеров: пак стоит, но вызовов нет.
- Нет `controls-touch`: управление сделано своим `dragReader`, потому что нужен
  **относительный** жест, а не виртуальный стик.
- Нет `collision-3d`-правил: трафика и препятствий пока нет.
