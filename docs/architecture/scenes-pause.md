# `scenes/Pause.ts` — пауза поверх заезда

**Роль:** оверлей, который кладётся на `play` (`push`) и не даёт нижней сцене
шагать. Содержит затемнение, заголовок и две кнопки.
**Строк:** 23. **Экспортирует:** `Pause` (сцена `pause`).
**Использует:** `control`, `showGraphic`.

## Код

```ts
export const Pause = {
    name: 'pause',
    enter(): void {
        game.spawn({
            id: 'shade', layer: 'hud', x: 360, y: 640,
            width: 720, height: 1280, tint: '#0d2934', alpha: 0.72,
        });
        showGraphic('pause-title', 360, 508);
        control('resume', 360, 639, () => game.scenes.pop());
        control('restart', 360, 740, () => game.scenes.go('play'));
        game.step('pause', () => {
            if (game.input.keyPressed('Escape') || game.input.keyPressed('KeyP'))
                game.scenes.pop();
        });
    },
};
```

## Что создаётся

| Объект | Значение |
|---|---|
| `shade` | прямоугольник 720×1280 по центру, `#0d2934`, alpha 0.72 — затемняет 3D, но не скрывает его |
| `pause-title` | надпись «ПАУЗА» на y = 508 |
| `resume` | кнопка на y = 639 → `pop()` |
| `restart` | кнопка на y = 740 → `go('play')` |

Слой `hud` — прямоугольник рисуется поверх 3D и под остальными элементами HUD этой
сцены. Внутри слоя порядок задаётся полем `z`, а при равном `z` — порядком спавна;
здесь у всех элементов `z = 0`, поэтому затемнение, созданное первым, оказывается
позади.

## Три пути управления сцены

| Способ | Код |
|---|---|
| `push('pause')` | из `Play` по кнопке или P/Escape |
| `pop()` | «ПРОДОЛЖИТЬ» или P/Escape — заезд продолжается как был |
| `go('play')` | «НАЧАТЬ СНАЧАЛА» — стек заменяется, `Play.enter()` строит новый заезд с центра |

Разница принципиальна:

- `pop()` **не** вызывает `Play.enter()` — состояние `run` и все объекты живы,
  скорость и дистанция сохраняются.
- `go('play')` уничтожает обе сцены и создаёт заезд с нуля (`openRoad()`), включая
  перестройку города.

## Почему шаг всё равно нужен

Сцена `pause` не двигает мир, но должна ловить клавиши. `game.step('pause', ...)`
вызывается, пока сцена верхняя; шаг `drive` нижней сцены в это время не идёт. Так
симуляция действительно замирает, а не «рисуется паузой».

## Что можно добавить

| Фича | Правка |
|---|---|
| громкость/звук | `control('sound', ...)` + `game.commands.mute()` |
| возврат на титул | `control('home', ...)` → `game.scenes.go('title')` |
| лучший результат | `game.save.read/write` |
| анимация появления | `game.tween.from(shade, { alpha: 0 })` |
