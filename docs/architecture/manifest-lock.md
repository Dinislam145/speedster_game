# `manifest.lock.json` — зафиксированный граф паков

**Роль:** результат разрешения зависимостей, записанный пекарней. Нужен, чтобы
сборка была воспроизводимой: одинаковые версии и одинаковые артефакты. Руками не
редактируется.

## Структура

| Поле | Что содержит |
|---|---|
| `kernel` | версия ядра (`3.0.0-2`) |
| `packs` | `id → версия` каждого пака, попавшего в сборку (25 штук) |
| `order` | порядок `use(...)` — тот же, что в `engine.ts` |
| `artifacts` | `id → sha-256` содержимого пака: если файл пака изменился, сборка заметит |

## Зачем порядок

Порядок зафиксирован, потому что паки **дополняют друг друга**: `render-3d` требует
`world:3d`, `model-files-3d` требует `world:3d`, `core-3d` включает всё остальное,
а `rig-orbit` должен быть добавлен после мира. Пекарня строит топологический порядок
и пишет его сюда; `engine.ts` повторяет его буквально.

## Когда меняется

- Добавили/убрали пак (`packs add` / правка `manifest.json` + `bake`).
- Обновили версию пака.
- Обновилось ядро.

Если `npm run -s build` ругается на несовпадение артефактов — обычно достаточно
`npm run -s bake`, чтобы пересобрать `engine.ts` и `game/docs/`.
