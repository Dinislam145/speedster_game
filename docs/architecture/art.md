# `art.ts` — меш сопла и дневное небо

**Роль:** единственная «рукописная» геометрия дневной части + фон. Всё, что делает
файл, происходит один раз при загрузке (`makeArt()` из `main.ts`).
**Строк:** 89. **Экспортирует:** `makeArt()`. **Импортирует:** только `game`.
**Используется:** `main.ts`, косвенно `vehicle.ts` (меш `jet`).

## Типы

```ts
type Point = [number, number, number];
type Station = [z: number, halfWidth: number, bottom: number, top: number];
```

`Station` — поперечное сечение корпуса: на каком `z`, какая полуширина, где низ и
верх. Из набора сечений «сшивается» корпус.

## `hull(name, stations)` — корпус из сечений

1. Каждое сечение превращается в **кольцо из 6 точек**:
   - `±0.65·w` по низу,
   - `±w` на 42 % высоты (самое широкое место),
   - `±0.69·w` по верху.
   Широкий «пояс» на 42 % — это скос борта, из-за которого корпус читается гранёным,
   а не цилиндрическим.
2. Между соседними кольцами — 6 квадов, каждый разбит на 2 треугольника
   (сначала `a,b,c`, потом `a,c,d`).
3. Торцы закрываются веером из 4 треугольников каждый.
4. Нормаль считается **на каждый треугольник** (векторное произведение рёбер) и
   пишется в каждую из трёх вершин. Поэтому грани не сглаживаются — плоскость
   видна.
5. Вершина = 8 float: `x y z nx ny nz u v`; UV нулевые (текстура не нужна).
6. `game.world3d.defineMesh(name, Float32Array)`.

### Что строится

```ts
hull('jet', [
    [-0.01, 0.155, -0.09, 0.09],
    [ 0.38, 0.105, -0.065, 0.065],
    [ 1.00, 0.006, -0.008, 0.008],
]);
```

| Сечение | z | полуширина | низ | верх |
|---|---|---|---|---|
| 1 | −0.01 | 0.155 | −0.09 | 0.09 |
| 2 | 0.38 | 0.105 | −0.065 | 0.065 |
| 3 | 1.00 | 0.006 | −0.008 | 0.008 |

Это конус длиной 1 единицу по +Z, сужающийся к острию. Используется дважды в
`vehicle.ts` (внешний факел и ядро), где `sz` задаёт длину в метрах, а `sx/sy` —
толщину. Итого 32 треугольника, 96 вершин.

## `game.paint('daylight', 720, 1280, ...)`

Рисует дневное небо в картинку 720×1280 (при `{ res: 1 }` — без удвоения, потому
что картинка и так во весь экран):

1. Вертикальный градиент `#66b7d4 → #b8dedf → #e0e8da`.
2. Солнце — диск `#fff1c4`, радиус 48, центр (519, 222).
3. Четыре плоских облака-«полки» многоугольниками `#eff4e7` (координаты
   `[x, y, w]` в таблице).

Фон используется как `game.background.picture('daylight', 'stretch')` в `highway.ts`.

## Что менять

| Хочу | Где |
|---|---|
| другое сопло | таблица `stations` в `makeArt()` |
| больше граней | число точек в кольце внутри `hull` (сейчас 6) и циклы `for (let i = 0; i < 6; i++)`, `i < 5` |
| другое небо | градиент/солнце/облака в `game.paint('daylight', ...)` |
| небо другого размера | аргументы `game.paint` (720×1280 — размер экрана) |
