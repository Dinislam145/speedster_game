# `vehicle.ts` — болид, крен, тяга и тень

**Роль:** собирает видимый болид из загруженной модели и нескольких примитивов и
отдаёт функцию обновления, которую каждый кадр зовёт `drive.ts`.
**Строк:** 62. **Экспортирует:** `spawnVehicle(night)`, `CRAFT_WIDTH`.
**Используется:** `drive.ts` (и через него `drive.ts` → `drive.ts`).
**Импортирует:** `game`, `type Mesh`.

## Константы

| Имя | Значение | Смысл |
|---|---|---|
| `CRAFT_WIDTH` | 2 м | ширина корпуса для `MAX_X` в `drive.ts` |
| `HOVER` | 0.58 м | высота **центра** модели над полотном |
| `BANK_LIMIT` | 0.19 рад ≈ 10.9° | максимальный крен |

## Что создаётся

| Объект | Меш | Позиция | Материал |
|---|---|---|---|
| `craft` | модель `kestrel` | `x=0, y=HOVER, z=0`, `size=4.13` | материалы `.glb` |
| `exhaust-1/+1` | `jet` | `x=±0.56, y=−0.222, z=1.965` | `#49d8f4`, `unlit`, `alpha 0.63` |
| `exhaust-core-1/+1` | `jet` | `x=±0.56, y=−0.19, z=1.965`, масштаб `[0.6, 0.48, 1]` | `#d0ffff`, `unlit` |
| `hover-shadow` | `cylinder` | `x=0, y=0.012, z=0.08`, размер `[1.98, 0.008, 3.25]` | ночь `#060c18` α0.62, день `#233b46` α0.25, `unlit` |

Сопла стоят на `z = +1.965`, то есть **сзади**, между болидом и камерой; `jet` —
конус, направленный по +Z, поэтому пламя тянется к камере. Тень — сплюснутый
цилиндр, эллипс 1.98 × 3.25 м.

## `spawnVehicle(night)` — что внутри

```ts
type Part = { obj: Mesh; x: number; y: number; z: number };
```

Внутренняя `part(...)` спавнит деталь и запоминает её локальные координаты, чтобы
потом вращать их вместе с корпусом. Модель корпуса создаётся отдельно:
`game.modelFiles.spawn('kestrel', { id: 'craft', size: 4.13, y: HOVER })`.

Возвращается замыкание:

```ts
(x, lateralSpeed, throttle, seconds, dt) => { ... }
```

| Параметр | Откуда | Смысл |
|---|---|---|
| `x` | `run.x` | боковая позиция, м |
| `lateralSpeed` | `shift / dt` | скорость смещения, px/с |
| `throttle` | `run.speed / CRUISE` | 0…1, доля тяги |
| `seconds` | накопленное время в `drive.draw` | для синусов |
| `dt` | шаг | сглаживание крена |

### Алгоритм кадра

1. **Цель крена:** `target = −clamp(lateralSpeed / 9, −1, 1) · BANK_LIMIT`.
   Знак минус — при движении вправо болид валится вправо (как мотоцикл).
2. **Сглаживание:** `bank += (target − bank) · (1 − e^(−13·dt))` — не зависит от FPS,
   полный переход примерно за 0.2 с.
3. **Парение:** `lift = HOVER + sin(seconds · 3.2) · 0.035` — ±3.5 см, период ~2 с.
4. Корпус: `craft.x = x`, `craft.y = lift`, `craft.roll = bank`.
5. Тень следует за `x` (не за креном) — так она читается как «под болидом».
6. Сопла поворачиваются вокруг точки крепления на тот же `bank`:
   ```ts
   obj.x = x + cos·lx − sin·ly
   obj.y = lift + sin·lx + cos·ly
   obj.roll = bank
   ```
   (поворот локального смещения на угол крена).
7. **Длина факела:**
   `length = 0.09 + throttle · (0.86 + 0.08 · sin(seconds · 32))`.
   Внешнее пламя — `length`, ядро — `0.66 · length`. На крейсерской скорости факел
   почти в 10 раз длиннее, чем на старте, и «дрожит» с частотой ~5 Гц.

## Почему модель, а не примитивы

`kestrel.glb` даёт узнаваемый силуэт (клин, фонарь, два сопла), которого не собрать
из коробок; при этом все копии — инстансы одного меша. Сопла и тень — примитивы,
потому что их надо масштабировать/красить в рантайме.

## Где править

| Хочу | Правка |
|---|---|
| шире/уже корпус | `size` в `modelFiles.spawn` + `CRAFT_WIDTH` |
| выше/ниже парит | `HOVER` |
| сильнее кренится | `BANK_LIMIT` |
| крен быстрее/медленнее | `13` в сглаживании |
| длиннее пламя | `0.86` в формуле длины |
| ярче/прозрачнее пламя | `alpha`, цвета `#49d8f4` / `#d0ffff` |
| заметнее тень | `alpha` в `spawn` тени |
