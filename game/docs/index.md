# speedster — composed engine

**Start with [make-a-3d-game.md](make-a-3d-game.md), and read it whole:** the whole surface in one page. The other pages are reference: look a thing up there when the page sends you, or for a pack you added.

This game composes `core-3d`, which brings `render-auto`, `world-3d`, `world-screen`, `rig-orbit`, `geometry-3d`, `render-3d`, `lighting-3d`, `maths`, `color`, `audio`, `ui`, `tween`, `save`, `particle-textures`, `particles-3d`, `feel`, `attach-3d`, `model-3d`, `collision-3d`; and `typography`, `backdrops`, `backdrop-sky`, `backdrop-stars`, `model-files-3d`.
Nothing else exists. Import `game` from `./engine.js`.
