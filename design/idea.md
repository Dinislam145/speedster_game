# Untitled game

Идея законченной игры.

## Концепция

Гиперказуальная мобильная гонка на антигравитационном болиде в стиле киберпанк-будущего.

- **Управление** — одним пальцем, только в пределах дороги.
- **Референс геймплея** — по смыслу похож на *Subway Surfers*.

## Локации

Геймплей происходит в разных локациях.

- **Стартовая локация** — ночной неоновый киберпанк-город.

## Механики

- **Препятствия на дороге** — другие автомобили, объекты (например, мусор).
- **Ускорение.**
- **Прыжки с трамплинов.**
- **Сбор монет.**
- **Начисление очков.**

## Режимы игры

Планируется несколько режимов. Сейчас в работе только **свободный заезд** — до реализации всех механик.

## Магазин

В игре будет магазин скинов:

- покупка разных болидов;
- настройка подсветки болида;
- настройка пламени из двигателя.
